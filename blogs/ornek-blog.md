# İlk Blog Yazım: Markdown Harika!

Siteme Markdown ile blog yazısı eklemek gerçekten çok kolaymış. Artık word kullanmama gerek yok.

## Markdown'da Neler Yapabilirim?

1. **Kalın metin** yazabilirim.
2. *İtalik metin* kullanabilirim.
3. Kod blokları ekleyebilirim:

```javascript
console.log("Hack the planet!");
```
